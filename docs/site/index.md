# Lume OS - Site Oficial

Bem-vindo ao Lume OS - SO Linux leve, premium e imutável.

## Visão Geral

Lume OS é um sistema operacional Linux desenvolvido para devolver vida a computadores fracos, oferecendo visual premium e desempenho otimizado em 3 edições: Lite, Core e Prime.

## Características Principais

- **Leve:** Idle de 250-450 MB de RAM
- **Imutável:** Base SquashFS+verity com update A/B
- **Seguro:** LUKS2, AppArmor, seccomp, nftables
- **Visual Premium:** Barra pílula, janelas de vidro, materiais
- **3 Edições:** Lite (i386), Core, Prime (amd64)

## Instalação

1. Baixe a ISO da edição desejada
2. Grave em pendrive com Rufus, Etcher ou Ventoy
3. Inicie pelo pendrive
4. Siga o OOBE (primeira execução)
5. Aproveite o Lume OS!
